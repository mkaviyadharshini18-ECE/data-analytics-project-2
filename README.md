# 📊 Student Performance Analysis - Data Cleaning & EDA | Project 2

## 📌 Project Overview
Cleaned and analyzed a messy student performance dataset containing missing values, duplicates, and inconsistent formats. Performed Exploratory Data Analysis (EDA) to extract meaningful insights about factors affecting student performance.

This is **Project 2** of my Data Analytics Portfolio.

## 🎯 Objectives
- Identify and handle missing values
- Clean inconsistent data formats
- Remove duplicate records
- Perform Exploratory Data Analysis (EDA)
- Visualize trends and correlations

## 🛠️ Tech Stack
- Language: Python
- Libraries: Pandas, NumPy, Matplotlib, Seaborn
- Tools: Jupyter Notebook, GitHub

## 📂 Repository Structure
- kaviyadharshini_project2.ipynb - Main analysis notebook
- Student_Performance_Messy (2).csv - Raw dataset
- README.md - Project documentation

## 🔍 Data Cleaning Steps Performed
1. Checked for missing values and null counts
2. Handled missing data using appropriate imputation
3. Standardized inconsistent text formats (e.g., Gender, Subject)
4. Removed duplicate entries
5. Converted data types for analysis

## 📈 Key Insights & Visualizations
- Distribution of student scores
- Correlation between study hours and performance
- Subject-wise performance comparison
- Gender-wise analysis
- Attendance vs Marks relationship

## 🚀 How to Run This Project
1. Clone the repository
2. Install libraries: pip install pandas numpy matplotlib seaborn
3. Open notebook in Jupyter and run all cells
